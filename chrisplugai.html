Put this page online for free, so friends can use it

This page is one file, so any free static host can serve it. GitHub Pages is the simplest to do from a phone or laptop.

  1. Tap Copy the page file above.
  2. On github.com, make a free account and create a new repository. Name it anything and set it to public.
  3. Choose Add file, then Create new file. Name it index.html and paste what you copied.
  4. Commit it. Then open Settings, then Pages, set the source to the main branch, and save.
  5. After a minute GitHub shows your link. Send it to your friends.

Netlify Drop and Cloudflare Pages also work: save the copied text as index.html and drag that file onto them. Everyone's brand hashtag and deck progress are saved in their own browser only.
